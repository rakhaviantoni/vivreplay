# Project direction

Reading this as: a card-library workbench for collectors and players, in a quiet archive-and-game-table visual language, dial ENERGY 2 / RHYTHM 2 / MOTION 1.

- The palette uses ink, aged paper, and one vermilion action color so card art retains visual priority.
- The desktop layout uses a compact top rail and a broad library canvas because card search is the first task, not a dashboard decoration.
- Editorial serif headings distinguish card identity and collection state; the interface uses a neutral sans-serif for filtering and account work.
- Rules and dividers suggest binder pages and card sleeves. They organize dense information without adding ornamental panels.
- Product actions are described by the thing they do: add a printing, open a deck, or show market listings.
- Motion is limited to state feedback and a short card lift on hover, because players need fast scanning and reduced-motion support.
- The supplied external card image is reserved for the single catalog record that declares it as a user-approved external source. Generated artwork remains the fallback for all other seed records.

## One Piece direction

The UI uses a midnight game table with muted nautical chart lines, compass geometry, and brass controls. These details belong to the play surface and navigation rather than being pasted into every card or label. Card art stays dominant, with the interface serving deck construction and collection work.
