# Courier marks used on shipping labels

The enabled courier images are stored in the `tcg-card-images` R2 bucket under `market/couriers/` and served by `/api/market-assets/couriers/{code}`.

The files were copied from the courier marks displayed on Biteship's [supported couriers page](https://biteship.com/en/product/plugin) on 15 October 2026. Biteship's [Courier API](https://biteship.com/en/docs/api/couriers/retrieve) does not return logo URLs. The marks identify the selected shipping carrier; each name and logo remains the property of its respective owner.
